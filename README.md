# Talent Dispatch 11.15 · 派遣岗位需求与到岗交接

FDE 全流程训练项目 · 上海外服（集团）有限公司 · 人才派遣场景。

> **合成演练声明**：本仓库全部材料基于合成场景访谈，需求均为待验证假设。只读核对与人工交接；**不代表真实授权、业务执行或客户验收**。覆盖率 36/36 仅表示访谈事实已采集，不等于需求确认或验收通过。

## 案例

- 初始诉求：岗位条件在电话中修改，交接单仍引用旧技能要求。
- 主问题提出人：林亦舟（派遣项目服务专员）；共同提出人：顾明岚（服务业务负责人）。
- 调查样本：一次具体事件；需记录场景与访谈证据编号。
- 需建立的基线：时效、返工、复核成本，基线须按样本验证。
- 边界：只读核对与人工交接；不预设根因、预算或承诺收益。

## 试点边界（不可越线）

- 一个批次的需求单 f05；仅脱敏只读导出，写回／外部消息／执行接口不开放 f32。
- 不自动决定录用或派遣资格、不向真实人员发送安排 f05 f52。
- 一线可提交变更、正式确认由业务负责人完成，模型没有审批权 f22；正式结论须授权人员确认 f41。
- 四周、两名骨干、每周不超四小时 f03；范围业务负责人定、质量侧可叫停、客户侧确认用途 f04。
